## Color Schemes Summary

- **Sunrise**: Pink → Red → Gold
- **Morning**: Orange → Light Orange → Yellow  
- **Midday**: Gold → Bright Yellow → Yellow
- **Late Afternoon**: Dark Orange → Orange → Goldenrod
- **Evening/Sunset**: Red-Orange → Tomato → Light Salmon
- **Dusk**: Saddle Brown → Sienna → Burlywood
- **Midnight**: Very Dark → Dark Slate → Gray
- **Late Night**: Black → Midnight Blue → Dark Slate
- **Early Morning**: Midnight Blue → Dark Slate Blue → Slate Blue
